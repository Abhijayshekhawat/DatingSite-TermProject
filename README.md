# CIS 3342 Team Project – Core MVC Web Application & Web APIs

This project was developed as part of the **CIS 3342** course, where my teammate and I applied all the techniques and concepts learned throughout the semester. Our goal was to build a fully functional **ASP.NET Core MVC** application, featuring **user login/registration**, **Web APIs**, **dynamic data displays**, and **secure data handling**. We also incorporated **Razor Views**, **Web API integration**, and **third-party APIs** to align with modern web development practices.

---

## Project Contributions

### ASP.NET Core MVC Application
- **Conversion from ASP.NET Web Application** (Project 3) to **ASP.NET Core MVC**.  
- Replaced ASPX pages with **Razor Views** for a modern front-end.  
- **My Role**: Handled **back-end integration** with APIs.  
- **Teammate**: Led the **front-end Razor View** design for consistency and navigation.

### Login & Registration System
- Implemented **cookie-based login** for faster access.  
- **Two-step email verification** and **retrieval of forgotten username/password**.  
- **My Role**: Handled **security questions** and **two-step verification** through the Web API.  
- **Teammate**: Managed **cookie storage**, retrieval logic, and design.

### Web API Development
- Developed **at least two RESTful APIs** with CRUD operations using **JSON**.  
- **Custom user-defined types** for data exchange.  
- **My Role**: Built **server-side logic** for Web API requests from Razor Views.  
- **Teammate**: Ensured **API security** and efficiency.  
- Together integrated a **third-party Web API**, avoiding any client-side code reliance.

### Multiple Profile Images & Dynamic Data Displays
- **Multiple image upload** and display for user profiles.  
- **My Role**: Implemented **dynamic data display** and layout.  
- **Teammate**: Implemented the **image upload** and user profile galleries.

### Stored Procedures & Security
- Used **stored procedures** for all database operations to prevent SQL injection.  
- **My Role**: Focused on **database interactions** and **encryption** of sensitive data.  
- **Teammate**: Optimized **stored procedures** for **performance** and **security**.

### Serialization & Learning Opportunity
- Implemented **serialization and deserialization** for data persistence.  
- **My Role**: Explored additional **serialization** techniques beyond built-in Web API functionality.  
- **New Feature** (My Role): **Dynamic chart generation**.  
- **Teammate’s New Feature**: Implemented a **SOAP ASMX Web Service**.

### CSS Styling & Navigation
- Used **CSS** and **Bootstrap** for a visually appealing interface.  
- **My Role**: Contributed to **layout styling**.  
- **Teammate**: Improved **navigation** for an intuitive user experience.  
- Provided **instructional labels** and **error messages** on each page.

### Equal Contribution
- Work was **evenly split** across design, database, Web APIs, and styling.  
- **My Role**: **Back-end API integration**, **security**, and **serialization**.  
- **Teammate**: **Front-end design**, **image handling**, and **SOAP web service**.
